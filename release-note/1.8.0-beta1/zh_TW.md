## [1.8.0-beta1]

### 新增
- 新增圖庫功能，支援新增照片來源，並可透過時間軸集中瀏覽照片與影片
- 新增智慧搜尋，支援透過自然語言、圖片中的文字及畫面內容尋找照片
- 新增地圖瀏覽，可依國家或地區、城市及地點查看照片
- 新增相簿、收藏與最近瀏覽，協助使用者更方便地整理及尋找重要照片
- 新增回憶功能，自動整理往年今日、地點回憶及旅程故事
- 新增 iCloud Drive、iCloud Photos 及百度網盤整合支援
- 新增部分裝置的風扇控制策略，提升散熱表現與運作穩定性

### 修復
- 修復無法修改系統時區的問題
- 修復裝置資訊中顯示的記憶體頻率與實際頻率不一致的問題
- 修復在部分情境下建立 RAID 時，視窗底部的「建立」按鈕可能被遮擋的問題
- 修復在部分情境下備份工作佔用過多系統資源的問題

### 優化
- 優化 Docker 應用程式生命週期管理，提升應用程式啟動、停止及狀態切換的可靠性
- 優化應用程式設定頁面的 CPU 資源上限邏輯，最高值會根據裝置資訊中偵測到的 CPU 執行緒數量自動判定
- 優化應用程式解除安裝流程，支援選擇刪除或保留應用程式資料
